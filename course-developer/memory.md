# 课程开发 · 记忆路由

## 路由总原则

记忆分三层存储，互不越界、不重复：

| 内容类型 | 落点 | 说明 |
|----------|------|------|
| 课程设计 / 大纲 / 教学内容 | **课程产物**（受治理，落 SAG 或项目库） | 教育资产，引用须带 `locked_contract` 出处 |
| 用户偏好 / 项目约定 / 跨会话上下文 | **本地 `memory.md`**（用户级 `~/.workbuddy/MEMORY.md` 或工作区 `.workbuddy/memory/`） | 跨项目通用偏好 |
| 方法细节 / skill 内部流程 | **不写** | Skill 是消耗品，知识库能调度即可，路由到「course-dev（名称可配置，可替换）」 |

## 回灌规则

- 课程产物回灌 SAG 须经**知识库架构师（GDT-KB）**编排，本角色不直接建索引。
- 引用的知识 / 数据 / 诊断素材，跨会话须从对应角色产物或 SAG 拉取，不依赖本地散落笔记。

## 禁止项

- 不把 skill 方法细节写进 memory（避免双源漂移）。
- 不把未公开财务、受益人 PII、未批准课程外发写入任何公开 / 共享层。
- 不在 memory 固化可被 skill 动态调度的口径。
